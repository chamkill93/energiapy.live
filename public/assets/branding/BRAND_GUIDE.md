# EnergiaPY.live — Brand Guide

**Nombre:** EnergiaPY.live  
**Dominio canónico:** `https://energiapy.live`  
**Claim principal:** “La energía de Paraguay, en tiempo real”.  
**Claim institucional alternativo:** “La energía de Paraguay, en datos”.

## Personalidad
Centro de control GIS moderno, técnico, sobrio, confiable y público. La interfaz debe transmitir trazabilidad de datos antes que espectáculo visual.

## Paleta
- Fondo noche `#04111d`
- Panel `#071827`
- Azul flujo / interacción `#2ea3ff`
- Verde sistema / Paraguay `#45e47f`
- Ámbar Yacyretá / alerta contextual `#ffb53c`
- Rojo error `#ff6470`
- Texto `#f4f8fb`
- Muted `#95adbf`

## Reglas
1. El mapa manda: 80–85% del espacio útil del viewport de la landing.
2. Paneles flotantes compactos y translúcidos, no una grilla de tarjetas.
3. Los colores deben codificar significado, no decorar.
4. Siempre mostrar `measured_at`, `collected_at`, fuente y calidad cuando un dato se abre en detalle.
5. El estado “STALE” se ve; nunca ocultar la antigüedad de una lectura.
6. No usar números del mockup como datos vivos.
